# Credit-Card-Fraud-Detection
This project is a Machine Learning pipeline designed to detect fraudulent credit card transactions. In the real world, fraud detection is a classic anomaly detection problem characterized by extreme class imbalance (often < 0.2% of transactions are fraudulent).

This project demonstrates how to handle highly imbalanced data using synthetic over-sampling and why traditional evaluation metrics like "Accuracy" are dangerously misleading in financial contexts.
